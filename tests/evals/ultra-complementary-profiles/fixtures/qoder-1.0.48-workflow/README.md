# Preserved Qoder 1.0.48 Workflow fixture

This deterministic fixture is a de-identified preservation of the Qoder 1.0.48
Workflow evidence captured in the historical Ticket 20 v2 reference attempt.
The protocol shape, successful terminal states, child roles, identity fields,
`result.rawResult`, and artifact relationships are retained. Host paths,
session/run/task/tool identifiers, free-form child output, and timestamps were
replaced with stable fixture values. It is intentionally independent of `.evals`
and is not a canonical manifest or a model run.
